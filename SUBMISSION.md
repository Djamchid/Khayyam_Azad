# Google Fonts submission readiness

Status: **not submitted, not guaranteed to be accepted.**

## Required work before a responsible submission
1. Confirm original Noto Nastaliq Urdu upstream source repository, its history, license notices, and Reserved Font Names.
2. Align family naming, embedded copyright fields, style and version IDs, OFL notices, and source.
3. Provide editable original outlines/complete authoritative sources, not only reverse-engineered TTX + compiled base.
4. Run FontBakery Google Fonts profile and HarfBuzz/Farsi shaping regression tests; record failures and fixes.
5. Publish under an owned, public GitHub repository and preserve revision history.
6. Explain a substantive distinction over the already included Noto Nastaliq Urdu, or contribute improvements upstream instead.
7. Open issue using the Google Fonts submission form linking to the public repository.
