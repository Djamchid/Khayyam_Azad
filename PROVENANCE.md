# Provenance

- Original project: Noto Nastaliq Urdu, by the Noto contributors and upstream copyright holders, released under SIL OFL 1.1.
- This project: Khayyam Azad. A modified derivative with experimental ornaments and outline modifications carried over from prior v0.1–v0.2 work. In v0.4 the v0.3 `ss01` feature was rolled back.
- v0.4 release contains ~1,141 glyphs and standard GSUB/GPOS composition. The deliverable uses the same unchanged v0.4 binary files provided during the working sessions.
- Version naming inside certain `name` records is inconsistent with release version (some strings mention `Preview`/`v0.2`). For visual fidelity these embedded strings have **not been altered** in the distributed v0.4 binary. A technical cleanup is required before formal submission.
- Do not state that these outlines were designed from scratch or that this is based on IranNastaliq.
- Original 2017 Google copyright text and other existing notices must remain in subsequent modified versions. Upstream source provenance/commit reference and any reserved font names still need legal review before on-boarding to Google Fonts.
